# Arctivius's Automoaton Monitor

This app is a stand-alone app for doing analysis on combat reports exported from ArcDps

![App Preview Image](/public/img/app_preview.png)

## Getting Started
First, run the development server:

```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Usage

- Upload supported xls files from battle reports ( sample files in public/data)
- Select report to view (e.g. Pdmg )
- Filter by Profession at the top by clicking - profession icon buttons
- Sort by a value in the report by changing - combo box
- Mouse over name to see where they are trending - across days
- In summary you can configure mininum number of days required to be in top/bottom 5.
